# 🎮 RPG 英雄管理器

一个基于 WinForms 的 RPG 英雄小队管理工具，支持英雄的增删改查、装备管理、数据存档与读档功能。本项目是面向对象编程、WinForms 桌面开发、JSON 序列化的综合实践。

---

## ✨ 功能清单

| 功能模块       | 说明                                                         |
| :------------- | :----------------------------------------------------------- |
| **英雄管理**   | 查看英雄列表、新增英雄、删除英雄                             |
| **英雄详情**   | 显示英雄名称、等级、性别、职业、攻击力、特殊属性、技能描述   |
| **背包管理**   | 查看背包装备列表、添加装备、删除装备                         |
| **数据持久化** | 一键保存游戏数据、退出时自动提示保存、启动时自动加载存档     |
| **职业系统**   | 支持战士、法师、刺客三种职业，每种职业拥有独立的特殊属性（耐力/法力/敏捷）和技能描述 |

## 🚀 快速开始

### 运行环境
- Visual Studio 2022 或更高版本
- .NET Framework 4.8 SDK

### 启动步骤
1. 克隆仓库到本地：
   ```bash
   git clone https://github.com/Hanssome-githabo/RPGGUI.git
   ```
2. 用 Visual Studio 打开 `RPGGUI.sln`
3. 按 `F5` 编译并运行
4. 首次启动会自动创建三名默认英雄（剑圣、阿狸、劫）及初始装备

## 🧩 核心类说明

```
public enum EquipmentType       // 装备类型（武器/护甲/饰品）
public struct Equipment         // 装备（名称、攻击力、血量、类型）
public abstract class Hero      // 英雄基类（抽象类）
    ├── Warrior : Hero         // 战士（耐力）
    ├── Mage : Hero            // 法师（法力）
    └── Assassin : Hero        // 刺客（敏捷）
```

### 关键属性

```csharp
public double TotalAttack => Attack + Bag.Sum(e => e.Attack);
```

> 只读属性，动态计算英雄的总攻击力 = 基础攻击力 + 背包所有装备攻击力之和，使用表达式体成员实现。


## 💾 存档机制

- 数据保存在程序运行目录下的 `save.json` 文件中
- 支持多态序列化（父类引用指向子类对象，JSON 自动通过 `[JsonDerivedType]` 识别具体类型）
- 程序启动时自动加载存档，无存档时自动创建默认英雄
